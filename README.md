# Factory Surveillance System

This project uses Python and OpenCV to monitor real-time video and detect objects for improving safety in factory environments.

## Features
- Real-time monitoring
- Object detection
- Safety improvement

## Tech Stack
- Python
- OpenCV
- Computer Vision

## Files
- train_model.py → training logic
- real_time_detect.py → real-time detection
- merge_datasets.py → dataset processing
- data.yaml → configuration
